# agents/ — 智能体目录（出厂为空）

出厂不随包携带任何智能体：多代理模式的主代理与子代理都由「能力包市场」提供
（见 `bundles/` 里的 `multi-agent-orchestration`、`web-pentest` 等包），在控制台
「平台管理 → 能力包」里安装后即刻生效。

不装任何包时，多代理会话仍然可以运行：编排主代理回落到内置提示
（plan_execute / supervisor 各有内置提示，deep 回落到 Eino 默认）。

本目录留给运维者自己的 `.md` 智能体定义：放进来即被扫描（除本 README 外，
`*.md` 都会被当作子代理定义读取），与包提供的智能体走同一张能力表。
